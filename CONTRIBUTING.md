# Contributing to Meridian

The project is in milestone 1 and is licensed under the [MIT License](LICENSE).

- Keep the source list curated. Adding a source is an editorial choice, not a scrape.
- Keep blocking checks in front of approve. Do not make auto-publish the default.
- Use public or fictional sample data. Never commit credentials, `.env` files, databases, or private preview tokens.
- Run `npm test` before opening a pull request. Add a regression test when you change checks, approval, or ingest.
